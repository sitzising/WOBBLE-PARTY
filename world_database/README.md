# WOBBLE PARTY World Database

Static World Browser catalog for WOBBLE PARTY.

## Layout

- index.json — list endpoint (array of world metadata)
- worlds/{id}.json — download endpoint: [{tbw:...}]

Default game URL:

https://raw.githubusercontent.com/sitzising/WOBBLE-PARTY/refs/heads/main/world_database/

Upload / report are not supported on this static catalog (use a Workers REST API for that).
